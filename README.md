# local-novel · 写小说（dsh-go 原生页）v0.7.0

一整页写作工作台：蒸馏母本 → 卷纲/人物/伏笔/资料 → 分块写正文 → 体检 → 写作包 → 回写 → 导出 → 云备份。

## 界面（v0.7.0 · 移动端四面板）

| 面板 | 入口 | 内容 |
|---|---|---|
| 写小说 | 胶囊「写作台」 | 首页（最近在写/四指标/常用入口）、作品（章节列表/新建/删除）、编辑器（8 行正文+保存态+续写/润色/改写/体检）、统计 |
| AI创作 | 插件页签 | 写作包、续写、润色、改写、剧情检查、人物分析、体检环、结果回写、起名/脑洞/简介/抽卡、拆解 |
| 资料库 | 插件页签 | 人物、世界观、大纲、伏笔、时间线、素材、技法卡 |
| 设置 | 插件页签 | 母本目录、指纹、模型偏好、云同步、关于 |

**自动保存**：正文输入 1.2s 防抖写盘，顶部显示「正在保存…／已保存 hh:mm／保存失败：原因」。

## 删书

- 书架 →「管理书架（删除）」→ 点一本书 → 底部弹出确认 →「删除它」
- 或者打开一本书，底部「删除本书」，同样走确认
- 删的是整个 `<bookId>/` 目录（章节、指纹、资料夹），确认前可以「算了」撤回

## 数据布局

```
~/.dsh/dsh-go/novel/
├── novel.json        书列表 / 母本目录 / 日更目标 / 技法卡 / 榜单热词 / WebDAV / 输出偏好
├── 母本/             放 txt（GBK 自动转码、去盗版站广告行）
├── log/YYYY-MM-DD.json
└── <bookId>/
    ├── book.json     章索引 + 卷纲 + 人物 + 伏笔 + 资料夹 + 本书母本目录
    ├── style.json    本书指纹
    └── c0001.json    { chunks:["…"], words }
```

## 母本目录与大文件

默认 `~/.dsh/dsh-go/novel/母本`，设置里可改成任意绝对路径（含 `/sdcard/Download/...`）。

整本 1–2 MB 的大 txt 不会被整份塞进统计：扫描时抽样（列表 4k 字、蒸馏 15 万字），**显示的字数仍按全文真实统计**，蒸馏实测 ~0.5s。三本不同题材混放会触发「母本风格不一致」提示，建议一本书一套母本。

## 写作闭环

1. 书页「生成本章」→ 写作包进输入框（不自动发送）
2. 你发送 → AI 出稿
3. 长按回复「存进本章」→ 追加到当前章最后一块
4. 「体检」→ 分数 + 逐条问题 + 敏感词

## 限制（协议决定，不是偷懒）

- 面板回调值 4 KiB → 每块 ≤1200 字，一章分 2–3 块
- 写作包 ≤1980 字（insert 上限 2000）；超了先丢母本片段再丢卷纲
- 处理函数 3 秒超时 → WebDAV 走 deferred（pending，45 秒）
- 章节列表单页 ≤50 条；面板 ≤120 组件 / 32 KiB
